# learnerslanding

Learner's Landing: a cozy study workspace that grows a pixel-art village as you focus.

- **`site/`**: the new website (Astro + React). See [`site/README.md`](site/README.md) to run, edit and deploy it.
- **`learners landing/`**: material from the original Blogger site (theme, screenshots, video list) and study notes.
- **Sprite packs** (`72 Character Free/`, `Little Animals Pack V3/`, `Sprite Pack 3/`, `Sprite Pack 6/`): original art assets. The site uses cropped copies in `site/public/sprites/`.
